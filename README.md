# Portfólio – Heitor Garcia Piovan

Meu portfólio pessoal, feito com **HTML, CSS e JavaScript puro**.

## Funcionalidades

- Seções: início, sobre, projetos, habilidades e contato
- Cards de projetos gerados a partir de uma lista em JavaScript (fácil de atualizar)
- Tema claro/escuro com preferência salva no navegador
- Efeito de digitação no título
- Animações ao rolar a página com `IntersectionObserver`
- Layout responsivo e respeito a `prefers-reduced-motion`

## Tecnologias

HTML5 · CSS3 (variáveis, Grid, Flexbox, `color-mix`) · JavaScript

## Como executar

Abra o arquivo `index.html` no navegador ou acesse a versão publicada no GitHub Pages.
